# Catalog management

Coti gives account administrators two complementary ways to maintain the supplier catalog from
the backoffice.

The product list supports searching, creating, editing, deactivating, and reactivating products.
Each product can carry a primary photo to make it easier for the team to identify while reviewing
quotes. Deactivation preserves past quotes and price history.

The price action beside each product lets administrators select a branch and edit its current price and optional
discount floor. Saving starts a new validity period for that branch and preserves earlier prices.
The Prices settings page links to this editor alongside the spreadsheet import and export tools.

For larger changes, administrators can download an Excel workbook populated with the current
catalog and the selected branch's prices. Existing product codes update their products when the
reviewed workbook is imported again; new codes create products. Changed prices start a new price
validity period, leaving older quotes and history untouched. Invalid rows are shown before
confirmation and are skipped instead of partially applying them.
Large previews reveal rows in batches; confirming still imports every valid row in the file.
